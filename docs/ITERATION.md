# 迭代优先级（主 Agent 决策）

原则：先跑通离线闭环，再接实物；先基础调参，后增强体验；每一阶段都可演示、可验收。

## v0.1 基础闭环（已验收）

- [x] 协议基准冻结：帧头/帧尾/CRC16-Modbus/小端 float/包类型
- [x] PC 协议编解码 + 单测（CRC 向量、粘包拆包、错帧重同步）
- [x] 通信层：串口/TCP 双传输、连接管理、断流检测
- [x] 上位机：端口连接、遥测实时曲线、PID 参数下发 + ACK 回显、CSV 导出
- [x] `fake_mcu` 模拟器：TCP 闭环，无硬件可演示全流程
- [x] 验收：模拟器下连接 → 曲线 → 下发参数 → 阶跃 → 导出 CSV 全通过；
      PC 147 项测试 + MCU 两个主机运行器通过（二轮复跑，见 `TEST_REPORT.md` 第 6 节）

## v0.2 调参增强

- [x] 阶跃测试：幅值/保持时长配置、`STEP_START`/`STEP_STOP` 命令、`STEP_EVENT`
      状态显示、PC 侧指标离线分析（超调 / 峰值 / 上升时间 / 调节时间 / 稳态误差）
      已接入界面；曲线标注阶跃时刻未实现

- [ ] 曲线交互待做：缩放复位、多曲线显隐切换
- [ ] 细调控件：滑杆 + 数值框联动；增量微调按钮
